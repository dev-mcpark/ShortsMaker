# ShortsMaker

AI 기반 YouTube Shorts 자동 생성 및 업로드 파이프라인입니다.

## 주요 기능
- **주제 선정 및 기획**: LLM을 활용한 트렌디한 주제 선정 및 Shorts 스크립트 작성
- **영상 생성**: Google의 **Veo3** 모델을 사용하여 고품질 영상 클립 생성
- **자동 편집**: 오디오(TTS), 배경음악, 자막 합성
- **자동 업로드**: YouTube API를 통한 Shorts 업로드
